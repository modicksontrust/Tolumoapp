Critical Rule — No Buttons on Explanatory Cards
Neither the Access Opportunities card nor the Skills Hub card should have any clickable button (no “Try it,” “Learn more,” “Get started,” etc.). These cards exist purely to explain what each feature offers. Actual access to either feature is only available after a user has signed up and is inside the platform — there is no landing-page click-through to either interface.
